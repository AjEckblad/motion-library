Directional tabs

Directional tabs is a DOM effect: content enters from the side of the tab you picked. One plain JavaScript file with no dependencies; add it with npx motion-library add directional-tabs.

Open it live, tune it and copy the code

What is Directional tabs?

Picking a category further right slides products in from the right; going back slides them from the left.

How does Directional tabs work?

Old content fades out moving the opposite way, new content enters from a fraction of the width, and the underline slides and stretches to the new label.

How do I add Directional tabs to my website?

  1. In your project folder, run npx motion-library add directional-tabs. It writes animations/directional-tabs.js. Needs Node 18 or newer.
  2. Import it and call it with a container element that has a size: import fx from './animations/directional-tabs.js'; const stop = fx(document.querySelector('#hero'));
  3. Call stop() to clean up, for example when a component unmounts.

Every setting below is also a flag, so you can install it already tuned: npx motion-library add directional-tabs --duration 800.
