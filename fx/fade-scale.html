Motion Library/Basics

Fade & scale in

Fade & scale in is a DOM effect: cards rise from 94% scale, never from zero. One plain JavaScript file with no dependencies; add it with npx motion-library add fade-scale.

Open it live, tune it and copy the code

What is Fade & scale in?

Tap a shop filter and the product cards leave quickly, then the new ones rise in turn.

How does Fade & scale in work?

Each card enters from 94% scale and transparent with a hard ease-out; the exit is shorter than the entrance, so new results never wait on old ones.

How do I add Fade & scale in to my website?

  1. In your project folder, run npx motion-library add fade-scale. It writes animations/fade-scale.js. Needs Node 18 or newer.
  2. Import it and call it with a container element that has a size: import fx from './animations/fade-scale.js'; const stop = fx(document.querySelector('#hero'));
  3. Call stop() to clean up, for example when a component unmounts.

Every setting below is also a flag, so you can install it already tuned: npx motion-library add fade-scale --duration 1200.
