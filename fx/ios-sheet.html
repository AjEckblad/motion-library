Motion Library/Page transitions

iOS sheet

iOS sheet is a DOM effect: the page steps back as the sheet comes up. One plain JavaScript file with no dependencies; add it with npx motion-library add ios-sheet.

Open it live, tune it and copy the code

What is iOS sheet?

Choose size slides a sheet up while the page behind shrinks, rounds its corners and dims.

How does iOS sheet work?

The sheet moves on translateY, the page on scale with a clip-path for its corners, under a fading black layer, all on one drawer curve.

How do I add iOS sheet to my website?

  1. In your project folder, run npx motion-library add ios-sheet. It writes animations/ios-sheet.js. Needs Node 18 or newer.
  2. Import it and call it with a container element that has a size: import fx from './animations/ios-sheet.js'; const stop = fx(document.querySelector('#hero'));
  3. Call stop() to clean up, for example when a component unmounts.

Every setting below is also a flag, so you can install it already tuned: npx motion-library add ios-sheet --duration 1000.

  const fit = () => {
    const W = stage.clientWidth, H = stage.clientHeight, f = Math.min(1, Math.max(0.66, 0.66 + (H - 260) / 240 * 0.34));
    const s = Math.min(H * 0.92 / (580 * f), W * 0.86 / 280), top = f >= 1 ? (H - 580 * s) / 2 : H * 0.05;

    // Reduced motion: the sheet fades in and out in place instead of sliding up.
    sheet.animate(reduce ? [{ transform: 'none', opacity: a }, { transform: 'none', opacity: b }] : [{ transform: up ? 'translateY(101%)' : 'none' }, { transform: up ? 'none' : 'translateY(101%)' }], o);

      { transform: up ? back : 'none', clipPath: `inset(0px round ${up ? 12 : 39}px)` },
    ], o);
    dim.animate([{ opacity: a * PARAMS.dim }, { opacity: b * PARAMS.dim }], o);
    sbW.animate([{ opacity: a }, { opacity: b }], { ...o, duration: o.duration * 0.6 });

  const timers = new Set();
  const later = (fn, ms) => { const id = setTimeout(() => { timers.delete(id); fn(); }, ms); timers.add(id); };

    later(() => { sizeEls.forEach(el => el.classList.remove('on')); present(true); }, 920);
    later(() => { tap(sizeEls[2]); sizeEls[2].classList.add('on'); }, 920 + PARAMS.duration + 700);

    }, 920 + PARAMS.duration * 2 + 1650);
    later(cycle, 920 + PARAMS.duration * 2 + 1650 + 1200);
  }
  cycle();

  return () => { timers.forEach(clearTimeout); ro.disconnect(); root.getAnimations({ subtree: true }).forEach(a => a.cancel()); root.remove(); };
}
