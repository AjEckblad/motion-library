Rubber-band drag

Rubber-band drag is a DOM effect: resistance grows past the edge, release springs back. One plain JavaScript file with no dependencies; add it with npx motion-library add rubber-band.

Open it live, tune it and copy the code

What is Rubber-band drag?

A photo viewer is swiped past its last photo, resisting more and more, then springs back on release.

How does Rubber-band drag work?

Inside the album the photo tracks the finger 1:1; past the end, Apple’s rubber-band formula shrinks the follow, and the return spring starts with the hand’s release speed.

How do I add Rubber-band drag to my website?

  1. In your project folder, run npx motion-library add rubber-band. It writes animations/rubber-band.js. Needs Node 18 or newer.
  2. Import it and call it with a container element that has a size: import fx from './animations/rubber-band.js'; const stop = fx(document.querySelector('#hero'));
  3. Call stop() to clean up, for example when a component unmounts.

Every setting below is also a flag, so you can install it already tuned: npx motion-library add rubber-band --constant 1.
