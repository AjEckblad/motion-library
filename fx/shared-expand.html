Shared-element expand

Shared-element expand is a DOM effect: FLIP with a uniform scale and a clip. One plain JavaScript file with no dependencies; add it with npx motion-library add shared-expand.

Open it live, tune it and copy the code

What is Shared-element expand?

A tapped product photo grows from its card into the page header and shrinks back on return.

How does Shared-element expand work?

FLIP from the card’s rect: lay the photo out as the header, transform it back onto the card, animate to zero; uniform scale plus a clip avoids stretching.

How do I add Shared-element expand to my website?

  1. In your project folder, run npx motion-library add shared-expand. It writes animations/shared-expand.js. Needs Node 18 or newer.
  2. Import it and call it with a container element that has a size: import fx from './animations/shared-expand.js'; const stop = fx(document.querySelector('#hero'));
  3. Call stop() to clean up, for example when a component unmounts.

Every setting below is also a flag, so you can install it already tuned: npx motion-library add shared-expand --duration 1500.
