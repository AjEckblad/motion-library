Motion Library/Springs & physics

Pull to refresh

Pull to refresh is a DOM effect: rubber-band pull, hold on a shelf, spring home. One plain JavaScript file with no dependencies; add it with npx motion-library add pull-refresh.

Open it live, tune it and copy the code

What is Pull to refresh?

Pulling an inbox down grows a spinner; the list holds on a shelf, then new mail slides in.

How does Pull to refresh work?

The pull follows a rubber-band curve, so resistance rises with distance; past the threshold the offset springs to a 56 px shelf, then back to 0 when done.

How do I add Pull to refresh to my website?

  1. In your project folder, run npx motion-library add pull-refresh. It writes animations/pull-refresh.js. Needs Node 18 or newer.
  2. Import it and call it with a container element that has a size: import fx from './animations/pull-refresh.js'; const stop = fx(document.querySelector('#hero'));
  3. Call stop() to clean up, for example when a component unmounts.

Every setting below is also a flag, so you can install it already tuned: npx motion-library add pull-refresh --stiffness 700.

// Pull to refresh: in a mail inbox a finger drags the list down; it follows less and less the further it goes, a spinner grows a spoke at a time, and on release the list springs to a 56 px shelf and holds while it spins. Then a new message slides in at the top and the list springs home.
// The rising resistance tells you how far is enough without a line on screen; the spokes filling in show progress before you commit, and the held shelf gives the work a place to happen before the result lands.

  // the simulated finger: keys are [ms, x, y, state(0 hidden, 1 hover, 2 pressed), linear?]; real touches take over for 2.5 s
