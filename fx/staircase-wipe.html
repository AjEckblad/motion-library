Motion Library/Page transitions

Staircase wipe

Staircase wipe is a DOM effect: bars cover in a stagger, the page swaps unseen. One plain JavaScript file with no dependencies; add it with npx motion-library add staircase-wipe.

Open it live, tune it and copy the code

What is Staircase wipe?

Next sends coloured bars down over a shop page in turn, revealing the next collection as they leave.

How does Staircase wipe work?

The bars cover the page, the content swaps while hidden, and the bars carry on downward instead of reversing; they take the next collection’s colour.

How do I add Staircase wipe to my website?

  1. In your project folder, run npx motion-library add staircase-wipe. It writes animations/staircase-wipe.js. Needs Node 18 or newer.
  2. Import it and call it with a container element that has a size: import fx from './animations/staircase-wipe.js'; const stop = fx(document.querySelector('#hero'));
  3. Call stop() to clean up, for example when a component unmounts.

Every setting below is also a flag, so you can install it already tuned: npx motion-library add staircase-wipe --bars 14.

// Staircase wipe: on a homeware shop's website, clicking "Next collection" sends bars down over the page one after another; the page swaps while it's hidden and the bars carry on out the bottom.
// The bars take the colour of the collection you're heading to, so the wipe already hints at the next page. They never reverse, which keeps the motion moving forward like turning a page.
