Blur crossfade

Blur crossfade is a DOM effect: a short blur hides the double image. One plain JavaScript file with no dependencies; add it with npx motion-library add blur-crossfade.

Open it live, tune it and copy the code

What is Blur crossfade?

Switching a shop category between grid and list view melts one layout into the other.

How does Blur crossfade work?

The old view fades out blurring and shrinking slightly; the new fades in later from blurred and slightly larger. The blur hides the double image; keep it under 20 px.

How do I add Blur crossfade to my website?

  1. In your project folder, run npx motion-library add blur-crossfade. It writes animations/blur-crossfade.js. Needs Node 18 or newer.
  2. Import it and call it with a container element that has a size: import fx from './animations/blur-crossfade.js'; const stop = fx(document.querySelector('#hero'));
  3. Call stop() to clean up, for example when a component unmounts.

Every setting below is also a flag, so you can install it already tuned: npx motion-library add blur-crossfade --duration 800.
