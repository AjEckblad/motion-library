Card stack swipe

Card stack swipe is a DOM effect: drag, stamp, throw; the stack springs up. One plain JavaScript file with no dependencies; add it with npx motion-library add card-stack-swipe.

Open it live, tune it and copy the code

What is Card stack swipe?

Photos are dragged right to keep or left to delete and thrown off, and the next card rises.

How does Card stack swipe work?

While dragged the card tilts with its offset and a KEEP or DELETE stamp fades in; the throw eases out and the cards behind ride springs into place.

How do I add Card stack swipe to my website?

  1. In your project folder, run npx motion-library add card-stack-swipe. It writes animations/card-stack-swipe.js. Needs Node 18 or newer.
  2. Import it and call it with a container element that has a size: import fx from './animations/card-stack-swipe.js'; const stop = fx(document.querySelector('#hero'));
  3. Call stop() to clean up, for example when a component unmounts.

Every setting below is also a flag, so you can install it already tuned: npx motion-library add card-stack-swipe --throwDuration 800.

const PARAMS = { throwDuration: 320, stiffness: 260, damping: 24 };
