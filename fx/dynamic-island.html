Dynamic island

Dynamic island is a DOM effect: one black box clipped to three springs: width, height and corner radius. One plain JavaScript file with no dependencies; add it with npx motion-library add dynamic-island.

Open it live, tune it and copy the code

What is Dynamic island?

On a lock screen the pill around the camera grows into a call, its timer, a music player and a countdown. Tap it to open or close the player.

How does Dynamic island work?

The shape is a clip-path whose width, height and radius are springs, so it overshoots a little and any change retargets it; the content fades out fast and in a beat later, with a short blur.

How do I add Dynamic island to my website?

  1. In your project folder, run npx motion-library add dynamic-island. It writes animations/dynamic-island.js. Needs Node 18 or newer.
  2. Import it and call it with a container element that has a size: import fx from './animations/dynamic-island.js'; const stop = fx(document.querySelector('#hero'));
  3. Call stop() to clean up, for example when a component unmounts.

Every setting below is also a flag, so you can install it already tuned: npx motion-library add dynamic-island --stiffness 700.
