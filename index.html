Questions

What is this?

A library of live web animations and effects. Each one is a single plain JavaScript file with no dependencies: hover a card to watch it, open it to read how it works, tune it with the sliders and take the code.

How do I get started?

Browse the library, find one you like and copy the code. It takes about 30 seconds. Or open an effect and copy the command next to “Install”, for example npx motion-library add confetti --pieces 300. Node.js 18 or newer is required.

Do the sliders change what npx installs?

Yes. Every slider you move is added to the command as a flag (--pieces 300), and the CLI writes those values into the file it copies. Reset the sliders and the command goes back to the defaults.

Can I copy the code by hand instead?

Yes. Copy puts the file, with your slider values, on the clipboard; Download .html gives you a page that runs on its own. Import the default export, call it with a container element that has a size, and call the function it returns to clean up.

Does it work with React, Vue or Svelte?

Yes. Call the function in your mount hook (useEffect, onMounted, onMount) with a ref to a sized element and return its cleanup. Prompt copies everything an AI coding assistant needs to fit it into your component.

Which browsers?

Every current browser. WebGL pieces need WebGL (all modern browsers have it); a few use WebGL2. Serve your page from a local server or your dev server, since browsers block modules opened as files.

Are they fast enough for phones?

Most run at 60 fps on a laptop and stay smooth on recent phones. The heaviest shaders have a quality or count slider: lower it for mobile, and only mount effects that are on screen.

Is this really free?

Yes. Everything is under the MIT-0 license. Use them anywhere, change them freely.
